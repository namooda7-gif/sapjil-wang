> 이 문서를 그대로 제미나이에게 보여주고 작업 의뢰하면 됩니다.
> 박삽돌(char_001) 기존 5장은 이미 있음. **추가로 생성할 분량 = 43장**.

## 🚨 지난 작업 실패 — 반드시 다시 생성 (16장 전부 폐기)

5/3 1차 작업본이 다음 두 가지 이유로 **게임에 사용 불가능**해서 전량 재작업이 필요합니다:

### 실패 원인 #1 — 파일이 PNG가 아니라 **JPEG**였음
- 파일 확장자만 `.png`였고, 실제 내부 데이터는 **JPEG 포맷**.
- JPEG은 **알파(투명) 채널이 물리적으로 존재하지 않아** 투명배경이 절대 불가능.
- 결과: 게임에 넣으면 캐릭터 주변에 단색 배경 사각형이 그대로 보임 → 흙더미·구덩이 위에 어색한 사각 자국이 남음.

### 실패 원인 #2 — 해상도/비율이 박삽돌과 다름
- 기존 박삽돌 idle: **1536 × 2752** (세로형, 약 9:16)
- 1차 작업본: **1024 × 1024** (정사각형)
- 결과: 캐릭터마다 발 위치·크기가 제각각이라 게임에서 정렬 깨짐.

### 재작업 시 반드시 지킬 것 (제미나이에게 명시 필수)
1. **출력 포맷을 명확히 "PNG with alpha channel (transparent background)"로 지정**
2. **해상도를 1536 × 2752로 고정** (박삽돌 idle과 동일)
3. **저장 시 파일을 PNG로 export** (JPEG 금지) — 가능하면 응답 메시지에 "format: PNG, alpha: yes" 라고 답하게 요구

> 1차 작업본 16장은 모두 덮어쓰기로 교체 예정.

## 2. 모든 이미지에 공통 적용되는 규칙 (필수)

### 🔴 기술 규격 (이게 틀리면 게임에 못 씀 — 100% 폐기 사유)

1. **포맷: PNG (RGBA 8-bit)** — JPEG 금지, JPEG을 .png 확장자로 저장하는 것도 금지
2. **알파 채널 필수** — 캐릭터 외부 영역은 완전 투명 (alpha = 0). 흰색·체크무늬·단색 배경 절대 금지
3. **해상도: 1536 × 2752 px (가로 × 세로, 세로형 9:16)** — 모든 포즈, 모든 캐릭터 동일
4. **파일명**: `char_XXX_상태.png` 소문자 (예: `char_002_idle.png`, `char_006_dig_hard.png`)

> ✅ 검증 방법: 생성 후 파일을 더블클릭해서 봤을 때 캐릭터 주변이 **체크무늬(투명)**로 보여야 정상. 흰색/단색이면 **JPEG일 가능성 높음 → 재생성 필요**.

### 🟡 캐릭터 배치 규격

5. **발이 이미지 하단에 닿을 것** — 게임 코드가 origin (0.5, 1.0) = "이미지 가로 중앙 + 세로 하단" 기준으로 캐릭터 발 위치를 정렬함. 발 아래 빈 공간(투명 픽셀)이 들어가면 캐릭터가 공중에 뜬 채로 표시됨.
6. **캐릭터를 이미지 가로 중앙에 배치** — origin 0.5 기준이라 좌우 어긋나면 정렬 깨짐.
7. **캐릭터 크기는 이미지 세로 90% 이상** 차지 — 너무 작으면 게임에서 작아 보임 (박삽돌 idle 참고).

### 🟢 일관성 규격

8. **동일 캐릭터 8포즈 일관성** — 같은 의상, 같은 머리, 같은 액세서리, 같은 채색 톤. **한 시트로 한 번에 생성하면 일관성 가장 좋음** (생성 후 8장으로 잘라서 저장).
9. **삽 색상·모양은 모든 포즈 동일** — 캐릭터마다 자기 전용 삽이 있고, 그 삽은 8포즈 내내 동일해야 함 (박삽돌은 갈색 자루 + 회색 날).
10. **6캐릭터 사이의 화풍 일관성** — 박삽돌 8포즈 시트를 항상 레퍼런스로 첨부해서 같은 톤·터치·렌더링 스타일 유지.

## 3. 8가지 포즈 상세 명세 (모든 캐릭터 공통)

### ① idle — 가만히 서 있음
- 두 손에 삽 들고 정면 응시
- 자연스러운 미소 또는 무표정
- **이 포즈가 화풍·비율의 기준점**

### ② dig — 보통 삽질
- 삽을 위에서 아래로 휘두르는 동작 컷
- 발 약간 벌리고 무릎 살짝 굽힘
- 평범한 표정 (집중)

### ③ combo — 신난 표정
- 활짝 웃는 입, 눈 반짝
- 한 손으로 V 또는 주먹 쥠 (다른 손은 삽)
- 살짝 점프하는 듯한 자세
- **콤보 10회 이상 시 표시**

### ④ surprise — 놀람
- 입 크게 벌리고 눈 동그랗게
- 두 손 위로 든 자세 (or 한 손은 입가)
- "헉!" 느낌
- **보물 발견 순간 + legendary 대박 연출용**

### ⑤ clear — 승리
- 삽 위로 번쩍 들고 양손 만세
- 환한 미소
- 약간 점프 / 발 한쪽 들기
- **레이어 클리어 시 표시**

### ⑥ tired ⭐ NEW — 지침/번아웃
- 어깨 축 처지고 등 굽음
- 헐떡이는 입, 땀방울 1~2개 머리 옆에 표시
- 삽 자루를 짚고 서 있음 (지팡이처럼)
- 눈 반쯤 감김 (피곤함)
- **SOUL 게이지 40% 미만 시 표시 → 위기감 시각화 핵심**

### ⑦ panic ⭐ NEW — 당황/혼남
- 식은땀 줄줄 (얼굴 옆에 큰 땀방울)
- 두 손 위로 들고 항복 자세 (삽은 발 옆에 떨어뜨림)
- 눈 동그랗게 + 입 작게 벌림 ("어어...")
- 살짝 뒤로 기울어짐
- **NPC(감리사·경비 등) 호통 들을 때 표시 → 코미디 핵심**

### ⑧ dig_hard ⭐ NEW — 강타
- 두 손으로 삽 꽉 잡고 위에서 강하게 내려치는 컷
- 인상 찡그림, 입 꽉 다물기 ("으드득")
- 한쪽 무릎 굽혀 체중 실음
- 어깨 힘 잔뜩
- **돌·타일 층에서 표시 → 손저린 연출과 시각 일치**

## 4. 캐릭터별 디자인 가이드 (5종)

### char_002 — 굴착용 (알바생)
- **정체성**: 어쩌다 삽질 중인 평범한 청년 (대학생 알바생)
- **외형**: 짧은 검정 머리, 마른 체형, 키 큼
- **의상**: 회색 후드 티셔츠 + 청바지 + 흰 운동화 / 후드는 살짝 어깨까지
- **소품**: 평범한 나무 손잡이 삽
- **색상 톤**: 회색 + 네이비 (무채색 위주)
- **표정 기본 톤**: 약간 무기력 / 체념한 듯한 분위기 ("이거 왜 하고 있지...")
- **특이 사항**: combo/clear 포즈에서도 너무 화려한 느낌은 X (소심한 기쁨)

### char_003 — 김파순 (베테랑 아줌마)
- **정체성**: 풍물시장 출신 억센 아줌마
- **외형**: 짧은 파마머리, 통통한 체형, 중년
- **의상**: 꽃무늬 몸뻬바지 + 면 셔츠 + 챙 넓은 모자 / 손에는 토시
- **소품**: 손때 묻은 견고한 삽 (사용감 있음)
- **색상 톤**: 빨강·노랑·꽃무늬 (채도 높게, 한국 시장 아줌마 느낌)
- **표정 기본 톤**: 자신감 넘침, 호탕 ("이 정도쯤이야~")
- **특이 사항**: panic 포즈도 당당함이 살짝 묻어남 ("아휴~ 죄송해요~")

### char_004 — 이땅녀 (씩씩한 여대생)
- **정체성**: 자연 다큐 보다가 빠진 여대생, 보물 사냥꾼 기질
- **외형**: 단발 또는 포니테일, 마른 체형, 활기찬
- **의상**: 야외 활동복 (트레이닝 바지 + 후드 + 캡모자) + 작업 장갑
- **소품**: 손잡이에 리본/스티커 붙은 가벼운 삽
- **색상 톤**: 민트 + 연두 + 화이트 (싱그러움)
- **표정 기본 톤**: 반짝거리는 호기심 ("뭐가 나올까!")
- **특이 사항**: surprise 포즈는 진짜로 신남 (다른 캐릭터보다 더 흥분)

### char_005 — 두디 (두더지)
- **정체성**: 진짜 두더지가 직업으로 삽질
- **외형**: 통통한 회색 두더지, 큼지막한 손바닥(삽질 특화), 분홍 코, 동그란 안경
- **의상**: 안 입거나 가벼운 작업 조끼만
- **소품**: 자기 키만 한 작은 삽
- **색상 톤**: 회색 + 분홍 (코) + 안경 동테 갈색
- **표정 기본 톤**: 진지함 (전문가 분위기)
- **특이 사항**:
  - 두 발로 서 있되 다리 짧음, 전체적으로 통통한 비율
  - tired 포즈에서 안경 흘러내림
  - panic은 안경 비뚤어짐

### char_006 — 멍삽 (강아지)
- **정체성**: 보물 탐지 특화 골든 레트리버
- **외형**: 황금색 털, 늘어진 귀, 큰 혀(살짝 내밀음), 까만 눈동자
- **의상**: 작업용 파란 멜빵바지 (앞주머니 있음)
- **소품**: 입에 물고 다닐 수 있는 작은 삽 (or 두 발로 잡음)
- **색상 톤**: 황금색 + 파란 멜빵 + 분홍 혀
- **표정 기본 톤**: 늘 신난 강아지 (헥헥)
- **특이 사항**:
  - 두 발로 서되 강아지 비율 유지 (꼬리 보임)
  - tired에서 혀가 더 길게 나오고 귀 처짐
  - clear에서 꼬리 흔드는 모션 표현 (한쪽으로 휜)
