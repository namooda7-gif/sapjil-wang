# 삽질왕 보물 이미지 생성 지침서 (Gemini용)

> **사장님 사용 순서**
> 1. 제미나이 채팅창 열기 (Nano Banana / 이미지 생성 가능한 모델)
> 2. 아래 §2의 **Layer 1 프롬프트** 블록을 그대로 복사해서 붙여넣기 → 전송
> 3. 결과 zip 받으면 사장님 PC에 저장 → Claude한테 "받았어" 알리기
> 4. Layer 2, 3, 4, 5, 6 — 같은 방식으로 5번 반복 (총 6번)
> 5. 6개 레이어 모두 완성되면 Claude가 한 번에 통합 적용
>
> **왜 한 번에 다 안 시키나**: 한 번에 114장은 화풍이 흐트러지고 슬라이싱이 실패함. 18~20장씩 6번이 안전.

---

## 1. 모든 레이어 공통 출력 규격 (제미나이가 어기면 폐기)

- **포맷**: PNG (RGBA 8-bit)
- **배경**: 투명 (alpha = 0)
- **해상도**: 각 보물 512 × 512 px (정사각형)
- **파일명**: `t_LLL_NN.png` 정확히 (예: `t_001_01.png` ~ `t_006_19.png`)
- **저장**: 한 폴더(`treasures/`) 안에 평탄 배치 → zip 압축 1개로 전달
- **응답 마지막에 보고**: `format: PNG, alpha: yes, size: 512x512, count: N`

**검증**: 파일 더블클릭 시 보물 주변이 체크무늬(투명)로 보여야 정상. 흰색·다른 색이 보이면 PNG 아님 → 재생성.

---

## 2. 레이어별 작업 프롬프트 (그대로 복붙)

> 각 프롬프트는 **단독으로 완전함**. 하나만 붙여넣으면 그 레이어 끝.
> Layer 2부터는 직전 레이어 결과(시트 또는 대표 PNG 1~2장)를 **첨부**해서 화풍 레퍼런스로 쓰면 일관성이 살아납니다.

## 3. 자가 검증 체크리스트 (제미나이가 응답 전 확인)

각 zip 안의 모든 PNG가 다음을 만족해야 함:

- [ ] 파일이 PNG 정상 (헤더 `\x89PNG`, JPEG `\xFF\xD8` 아님)
- [ ] 알파 채널 존재 (RGBA, color type 6)
- [ ] 해상도 정확히 512 × 512
- [ ] 보물 외 영역 alpha = 0 (투명)
- [ ] 등급별 외곽 효과 명세대로 (common 글로우 X / rare 시안 / epic 보라 / legendary 황금)
- [ ] 같은 레이어 안에서 화풍 통일 (outline 두께·채도·렌더링 일관성)
- [ ] 실제 상표·로고·인물 사용 0
- [ ] 파일명 정확히 `t_LLL_NN.png` 규칙
- [ ] 폴더 안 누락 없음 (Layer 1·2 = 18장, Layer 3·6 = 19장, Layer 4·5 = 20장)

> 한 항목이라도 어긋나면 저장하지 말고 **재생성**.

## 4. 사장님이 받은 후 Claude한테 알릴 내용

```
"layer_N zip 받았어. 경로: <PC 경로>"
```

저는 즉시:
1. zip 압축 해제 → `public/assets/treasures/` 안에 PNG 평탄 배치 (기존 동명 파일 덮어쓰기)
2. `BootScene.js` preload 라인 자동 갱신 (현 53장 → 114장)
3. `GameScene.flyTreasureToHUD()` / `MuseumScene` 등 textures.exists 통과 → 자동으로 PNG 사용 (이모지 fallback 자동 비활성)
4. 빌드 검증 + 푸시

emoji는 layers.js에 그대로 유지 (만약의 누락 안전망).

## 5. 트러블슈팅

**Q. 제미나이가 "이미지를 못 만들어요" 라고 함**
→ 다른 이미지 생성 모델로 전환 (Imagen 3 / Gemini Nano Banana 등). 텍스트 전용 모델은 X.

**Q. 받은 PNG가 흰 배경으로 보임**
→ JPEG 가능성 큼. 파일을 텍스트 에디터로 열어 첫 4바이트 확인 (PNG는 `\x89PNG`).
→ 동일 프롬프트로 재요청. 출력 규격 부분 재강조.

**Q. 화풍이 레이어마다 다름**
→ Layer 2부터는 직전 레이어 결과물(시트 또는 대표 PNG)을 첨부 + "이 화풍으로" 명시.
→ 색감·outline 두께·등급별 글로우 일관성 재요구.

**Q. 슬라이싱이 어긋남 (보물이 잘림)**
→ 시트 그리드 좌표 재확인 요청. 각 칸 정확히 512×512 시작 좌표 (0,0), (512,0), (1024,0) ... 명시.
