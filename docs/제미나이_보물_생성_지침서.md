# 삽질왕 보물 이미지 생성 지침서 (Gemini Nano Banana 용)

> 이 문서를 그대로 제미나이에게 보여주고 작업 의뢰하면 됩니다.
> 현재 게임은 보물을 emoji 텍스트(🔨, 🪙 등 100px)로 표시 중. 등급 일관성·고유 디자인이 부족해서 PNG로 교체.
> **총 42장 (layer 1~6 × 7개 보물)**.

## 🚨 캐릭터 1차 작업본이 JPEG/1024로 폐기됐던 사례 — 이번에도 같은 실수 반복 금지

캐릭터 작업 때 .png 확장자만 쓰고 내부 데이터가 JPEG라 알파 채널 없음 + 1024 정사각형이라 비율 안 맞아서 16장 전량 폐기됐습니다. 보물도 같은 함정.

**제미나이에게 명시 필수:**
1. 출력 포맷 = `PNG with alpha channel (transparent background)` 명시
2. 해상도 = 512 × 512 px 고정
3. 저장은 PNG로 export (JPEG 금지). 응답 메시지에 "format: PNG, alpha: yes, size: 512×512" 라고 답하게 요구

## 2. 공통 기술 규격 (이게 틀리면 폐기 사유)

### 🔴 절대 규격
1. **포맷: PNG (RGBA 8-bit)** — JPEG 금지, JPEG을 .png 확장자로 저장하는 것도 금지
2. **알파 채널 필수** — 보물 외 영역 완전 투명 (alpha = 0). 흰색·체크무늬·단색 배경 절대 금지
3. **해상도: 512 × 512 px (정사각형)** — 모든 보물 동일
4. **파일명**: `t_LLL_NN.png` 소문자 (예: `t_001_01.png` ~ `t_006_07.png`) — layers.js의 id 그대로

> ✅ 검증: 더블클릭해서 봤을 때 보물 주변이 **체크무늬(투명)**로 보여야 정상. 흰색이면 JPEG 의심 → 재생성.

### 🟡 배치 규격
5. **보물을 이미지 정중앙에 배치** — 가로/세로 모두 center
6. **보물 본체는 이미지 크기의 75~85%** 차지 — 너무 작으면 게임에서 안 보이고, 너무 크면 글로우 효과 잘림
7. **글로우/sparkle 등 효과는 본체 외곽 ~10% 여유 영역까지** 사용 (이미지 끝에 닿지 않게 5% 패딩 유지)

### 🟢 일관성 규격
8. **같은 레이어의 7개 보물은 같은 화풍** — 한 시트로 묶어 그린 후 잘라서 저장 권장 (캐릭터 8포즈 시트와 동일 패턴)
9. **6개 레이어 사이 화풍 일관성** — layer_001 시트를 레퍼런스로 첨부해서 톤 유지

| 등급 | 색 시그니처 | 외곽 효과 | 디테일 |

> 같은 "양말"도 common(흔한 양말)과 rare(베란다 양말)는 시각적으로 달라야 함. common은 그냥 양말 그림, rare는 살짝 빛나면서 외곽에 시안 글로우.

저는 받은 즉시:
1. `public/assets/treasures/`로 정리·이동 (폴더 신규 생성)
2. `BootScene.js`에 preload 라인 42줄 추가
   ```js
   for (let L = 1; L <= 6; L++) {
       for (let N = 1; N <= 7; N++) {
           const id = `t_${String(L).padStart(3,'0')}_${String(N).padStart(2,'0')}`;
           this.load.image(id, `assets/treasures/${id}.png`);
       }
   }
   ```
3. `GameScene.js flyTreasureToHUD()`의 emoji 텍스트(line 1279~1281)를 image 객체로 교체
   - 텍스처 존재 시 `add.image(id)`, 없으면 기존 emoji fallback (개발 중 누락 안전망)

5. emoji는 layers.js에 그대로 유지 (fallback용 + 일부 UI에서 계속 사용 가능)
