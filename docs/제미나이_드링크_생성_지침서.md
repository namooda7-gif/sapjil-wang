# 삽질왕 에너지 드링크 이미지 생성 지침서 (Gemini용)

> **사장님 사용 순서**
> 1. 제미나이 채팅창 열기 (Nano Banana / 이미지 생성 가능한 모델)
> 2. 아래 §2의 **드링크 시트 프롬프트** 블록을 그대로 복사해서 붙여넣기 → 전송
> 3. 결과 zip 받으면 사장님 PC에 저장 → 외부 BG 제거 도구로 투명 처리(이미 투명이면 스킵)
> 4. `public/assets/drinks/` 폴더에 4장 평탄 배치 후 Claude한테 "받았어" 알리기
> 5. Claude가 BootScene preload + GameScene 이모지 → PNG 교체 일괄 적용

---

## 1. 출력 규격 (제미나이가 어기면 폐기)

- **포맷**: PNG (RGBA 8-bit)
- **배경**: 투명 (alpha = 0)
- **해상도**: 각 드링크 **512 × 512 px** (정사각형)
- **파일명**: 정확히 4개
  - `drink_sapcas.png` — 삽카스 (박카스 패러디)
  - `drink_hotsaps.png` — 핫삽스 (핫식스 HOT6 패러디)
  - `drink_redsap.png` — 레드삽 (레드불 Red Bull 패러디)
  - `drink_energasap.png` — 에너자삽 (가공의 황금 슈퍼 음료)
- **저장**: 한 폴더(`drinks/`)에 4장 평탄 배치 → zip 1개
- **응답 마지막**: `format: PNG, alpha: yes, size: 512x512, count: 4`

**검증**: 파일 더블클릭 시 음료 주변이 체크무늬(투명)로 보여야 정상. 흰색·다른 색이 보이면 PNG 아님 → 재생성.

---

## 2. 드링크 시트 프롬프트 (그대로 복붙)

```
삽질왕 게임의 에너지 드링크 4종을 같은 화풍·구도로 만들어줘.

[출력 규격 - 절대 어기지 말 것]
- 포맷: PNG with alpha channel (RGBA 8-bit)
- 배경: 투명 (alpha = 0)
- 해상도: 각 드링크 512 × 512 px (정사각형)
- 작업 방식:
  1) 2열 × 2행 그리드 시트(1024×1024)에 4개를 한 번에 그리기
  2) 시트를 칸별로 정확히 자르기 (각 칸 512×512)
  3) 각 칸을 개별 PNG로 저장. 파일명 정확히 다음 4개:
     - 좌상단: drink_sapcas.png
     - 우상단: drink_hotsaps.png
     - 좌하단: drink_redsap.png
     - 우하단: drink_energasap.png
  4) 자른 PNG가 알파 채널 살아있는 512×512 인지 검증
  5) 4장을 폴더 drinks/에 모아 zip 압축
- 응답 마지막: "format: PNG, alpha: yes, size: 512x512, count: 4"
- 흰색·단색 배경 금지, JPEG 금지, 1024 등 다른 해상도 금지

[배치 규칙 - 모든 드링크 공통]
- 음료 용기를 이미지 정중앙 배치
- 용기 본체는 이미지 70~80% 차지 (라벨 글자가 인식 가능한 사이즈)
- 외곽 5% 패딩 (글로우/그림자가 잘리지 않게)
- 용기 아래 옅은 타원 그림자 1개
- 정면 또는 살짝 (15도) 사선 각도 — 라벨이 정면에서 잘 보이게
- 미세한 한국적 디테일(흙 자국, 손때) 1~2 곳 — 게임 톤(노가다 정서)과 어울리게

[톤]
- 카툰 일러스트 (사실적 사진 X)
- B급 코미디, 한국 노가다 정서 (현장에서 마시는 느낌)
- 시각적 인지도 우선 — 멀리서 봐도 어떤 음료인지 즉시 구분되어야 함
- 패러디는 시각적 톤만 차용 (브랜드 로고/상표 텍스트 직접 복제 X — 패러디 명칭 그대로 사용)

────────────────────────────────────
[드링크 1] drink_sapcas.png — 삽카스 (박카스 패러디)
────────────────────────────────────
- 패러디 원본: 한국 박카스 (자양강장제, 1963년~)
- 용기: 작은 갈색 유리병 (~100ml 크기), 짧은 목, 노란 알루미늄 뚜껑
- 라벨 (병 가운데 둘둘 두른 직사각형):
  · 메인 색상: 노란색 바탕 + 검정 굵은 보더
  · 큰 글자 한국어 "삽카스" (박카스 폰트 톤 — 굵고 둥근 산세리프)
  · 부제 "맛있다 삽카스" 또는 "현장의 친구"
  · 박카스의 D 마크 자리에 → "삽" 한자 또는 작은 흙삽 아이콘
- 색 팔레트:
  · 병: 갈색 0x6b3a1a
  · 라벨: 노랑 0xfff200, 검정 글자
  · 액체: 갈색 (병 안 비치는 톤)
- 작은 디테일: 병 표면에 살짝 흙 묻은 자국 1~2

────────────────────────────────────
[드링크 2] drink_hotsaps.png — 핫삽스 (핫식스 HOT6 패러디)
────────────────────────────────────
- 패러디 원본: 한국 핫식스 (Lotte 칠성, 빨간 캔)
- 용기: 알루미늄 캔 (~250ml 사이즈), 위/아래 살짝 굴곡
- 라벨 (캔 전체):
  · 메인 색상: 강렬한 빨강 바탕
  · 굵은 회색 사선 (좌상→우하 대각선) — 핫식스의 그 사선 디자인
  · 큰 영문 글자 "HOT SAPS" (또는 "HOT 6삽") — 굵은 화이트 산세리프, 외곽 검정 stroke
  · 핫식스의 "6" 자리에 → "삽" 한자 또는 작은 삽 아이콘
  · 부제 "에너지 음료" 또는 "ENERGY DRINK"
- 색 팔레트:
  · 캔: 빨강 0xff3030
  · 사선/디테일: 회색 0x666666 + 흰색
- 작은 디테일: 캔 위쪽 뚜껑에 손때 자국 (현장 핵심 음료감)

────────────────────────────────────
[드링크 3] drink_redsap.png — 레드삽 (레드불 Red Bull 패러디)
────────────────────────────────────
- 패러디 원본: 레드불 Red Bull (오스트리아, 청+은 캔, 두 황소 마크)
- 용기: 슬림 알루미늄 캔 (~250ml 슬림), 길쭉한 비율
- 라벨 (캔 전체):
  · 메인 색상: 청은색 — 위쪽 진한 파랑 0x1a4d8c, 아래쪽 은색 0xc8c8c8 그라데이션
  · 가운데 마크: 두 마리 황소 → **두 마리 두더지** (또는 두 자루 삽 X자) — 노랑 마크
  · 큰 영문 글자 "REDSAP" — 위쪽에 빨간색 굵은 산세리프, 외곽 흰 stroke
  · 부제 "ENERGY DIG" 또는 "에너지 삽질"
- 색 팔레트:
  · 캔 위: 진한 파랑 0x1a4d8c
  · 캔 아래: 은색 0xc8c8c8
  · 마크: 노랑 0xffd700
  · 글자: 빨강 0xff3030
- 작은 디테일: 캔 표면에 약간의 결로(차가운 음료감)

────────────────────────────────────
[드링크 4] drink_energasap.png — 에너자삽 (가공의 황금 슈퍼 음료, 신화 등급)
────────────────────────────────────
- 패러디 원본: 가공의 황금 에너지 음료 (Monster Energy 톤 차용 — 검정+황금)
- 용기: 굵은 알루미늄 캔 (~500ml 톨 캔), 압도적 사이즈
- 라벨 (캔 전체):
  · 메인 색상: 검정 바탕 + 황금 메탈릭 액센트
  · 가운데 큰 마크: 황금 번개 (⚡ 모양, Monster의 발톱 자리) + 외곽 글로우
  · 큰 영문 글자 "ENERGASAP" — 황금색 굵은 산세리프, 외곽 검정 stroke
  · 부제 "MAX POWER" 또는 "신화 에너지"
- 색 팔레트:
  · 캔: 검정 0x000000
  · 황금 액센트: 0xffd700
  · 글로우: 노란빛 외곽
- 작은 디테일: 캔 자체가 살짝 빛나는 메탈릭 광택, 신화급 위엄 (다른 3종보다 한 단계 위 톤)

[중요]
- 4장 모두 같은 화풍·붓 두께·외곽선 톤이어야 함 (시트로 같이 그려야 일관성 보장)
- 시트 그릴 때 각 칸 사이에 8~10px 안전 마진 (split 시 잘림 방지)
- 용기 사이즈는 시각적으로 박카스 < 핫식스 < 레드불 ≤ 에너자삽 순으로 살짝 단계감 (등급감 전달)
- 글자가 작거나 흐릿하면 폐기 — 사장님이 인게임 64~100px로 보일 때도 라벨 인지 가능해야 함
```

---

## 3. 사장님 후처리 (zip 받은 후)

1. zip 풀고 4장 PNG 확인 (체크무늬 배경 = 투명 OK)
2. 만약 흰 배경 / JPEG로 왔으면 → BG 제거 도구로 한 번 더 처리 (캐릭터 워크플로와 동일)
3. `public/assets/drinks/` 폴더 생성 후 4장 이동
4. Claude에 "받았어" 알리기 → 자동 적용:
   - `BootScene` preload에 4 키 추가 (`drink_sapcas` 등)
   - `GameScene.launchDrinkFall`의 이모지 `def.emoji` 참조 → PNG 텍스처 사용으로 교체
   - 미로드 시 기존 이모지 폴백 (자산 깨짐 안전)

---

## 4. 검수 체크리스트 (적용 전 사장님 직접 확인)

- [ ] 4장 모두 512×512, 투명 배경
- [ ] 박카스 패러디(삽카스)가 박카스 형태 인지됨 (갈색 병 + 노란 라벨)
- [ ] 핫식스 패러디(핫삽스)가 핫식스 형태 인지됨 (빨강 캔 + 사선)
- [ ] 레드불 패러디(레드삽)가 레드불 형태 인지됨 (청은 캔 + 두 마리 마크)
- [ ] 에너자삽이 신화급 위엄 (다른 3종보다 한 단계 위)
- [ ] 라벨 글자가 멀리서도 읽힘 (캔/병 크기 ≥ 이미지 70%)
- [ ] 4장 화풍 일관 (붓 두께/색 톤/외곽선 같음)
- [ ] 글로벌 출시 정책 OK (브랜드 로고/상표 직접 복제 없음, 패러디 명칭만)
