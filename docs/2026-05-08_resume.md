### 시트 공통 규격
- 한 시트 = 가로 N칸 × 세로 1줄 (바로 자르기 쉬움)
- 각 칸 1024×1024 (시트 폭 = 1024 × N)
- 등급별 글로우: rare 시안 (반경 30) / epic 보라 + sparkle 3 / legendary 황금 후광 + 광선 4 + sparkle 5
- 카툰 톤, B급 코미디, 검정 outline 2~3px
- 상표 회피 필수 (편의점/막걸리/지폐 인물 등 패러디 또는 일반화)
- 보물 본체 75~85% 차지 + 외곽 5% 패딩

### 받은 후 통합 워크플로
1. 시트 6장을 `public/assets/treasures/sheet_layer{N}.png`로 저장
2. Python으로 가로 N칸 분할 + bbox 자동 추출 + 512×512 리사이즈 → `t_LLL_NN.png`
   - 이전 워크플로 코드 재활용 (sheet2 처리 코드 참고)
3. BootScene.js preload 보강 (현재는 신규 61종 미등록, 추가 필요)
4. 빌드 검증 + dev 서버 확인
