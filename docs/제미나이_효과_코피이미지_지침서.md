# 삽질왕 코피 효과 이미지 생성 지침서 (Gemini용)

> **사장님 사용 순서**
> 1. 제미나이 채팅창 열기 (Nano Banana / 이미지 생성 가능한 모델)
> 2. 아래 §2 프롬프트 블록을 그대로 복사해서 붙여넣기 → 전송
> 3. 결과 PNG 받으면 외부 BG 제거 도구로 투명 처리(이미 투명이면 스킵)
> 4. `public/assets/effects/` 폴더 생성 후 1장 저장 → Claude한테 "받았어" 알리기
> 5. Claude가 BootScene preload + GameScene 코피 트리거에 자동 오버레이 적용

---

## 1. 출력 규격 (제미나이가 어기면 폐기)

- **포맷**: PNG (RGBA 8-bit)
- **배경**: 투명 (alpha = 0)
- **해상도**: **512 × 512 px** (정사각형)
- **파일명**: `effect_nosebleed.png` (정확히)
- **저장**: `effects/` 폴더에 단독 → zip 또는 직접 전달
- **응답 마지막**: `format: PNG, alpha: yes, size: 512x512, count: 1`

**검증**: 파일 더블클릭 시 효과 주변이 체크무늬(투명)로 보여야 정상.

---

## 2. 프롬프트 (그대로 복붙)

```
삽질왕 게임의 "코피 펑!" 만화 효과 이미지 1장을 만들어줘.

[출력 규격 - 절대 어기지 말 것]
- 포맷: PNG with alpha channel (RGBA 8-bit)
- 배경: 투명 (alpha = 0)
- 해상도: 512 × 512 px (정사각형)
- 파일명: effect_nosebleed.png
- 응답 마지막: "format: PNG, alpha: yes, size: 512x512, count: 1"
- 흰색·단색 배경 금지, JPEG 금지

[배치 규칙]
- 효과를 이미지 정중앙에 배치
- 효과 본체는 이미지 80~90% 차지 (멀리서도 인지 가능)
- 외곽 5% 패딩 (글로우 잘리지 않게)
- 좌우 대칭 — 캐릭터 얼굴 중앙(코)에 오버레이될 것이라 좌우 균형 중요

[디자인 — "코피 펑!" 만화 효과]
- 메인 요소: 빨간 코피 분수
  · 중앙에서 위로 솟구치는 빨간 액체(피) 줄기 — 굵직한 만화 표현, 현실적 X
  · 끝부분이 작은 물방울들로 흩어짐 (위·좌·우 사선)
  · 색: 진한 빨강 0xc8102e ~ 밝은 빨강 0xff3030 그라데이션
- 보조 요소:
  · 만화 충격선 (impact lines) — 중앙에서 사방으로 뻗는 8~12개의 굵은 노란/흰 라인
  · 작은 별 마크 4~6개 (외곽 ★, 노란색 0xffd700)
  · 만화 효과 글자 (한국어): "푹!" 또는 "콸!" 굵은 검정 산세리프, 외곽 흰 stroke
    — 글자 위치: 우상단 또는 좌상단 (얼굴 중앙 가리지 않게)

[톤]
- 카툰 일러스트 (사실적 X)
- B급 코미디, 한국 만화 효과 톤 (소리효과 만화 그림체)
- 시각적 임팩트 강함 — "콤보 100 도달했다!" 인지 강화
- 외곽 검정 stroke 굵게 (캐릭터 위에 겹쳐도 또렷하게 보이게)
- 살짝 비대칭 / 손그림 느낌 OK (만화 톤)

[색 팔레트 정리]
- 빨강 (피): 0xc8102e ~ 0xff3030
- 노랑 (충격선/별): 0xffd700
- 흰 (글자 stroke / 작은 하이라이트): 0xffffff
- 검정 (외곽선): 0x000000
```

---

## 3. 사장님 후처리 (PNG 받은 후)

1. PNG 더블클릭 → 체크무늬 배경 = 투명 OK
2. 만약 흰 배경 / JPEG로 왔으면 → BG 제거 도구로 한 번 더 처리
3. `public/assets/effects/` 폴더 생성 후 PNG 이동
4. Claude에 "받았어" 알리기 → 자동 적용:
   - `BootScene` preload에 `effect_nosebleed` 키 추가
   - `GameScene.triggerNosebleed`에서 빨간 점 graphics 대신 PNG 오버레이 사용
   - 미로드 시 기존 빨간 점 폴백 (자산 깨짐 안전)

---

## 4. 검수 체크리스트 (적용 전 사장님 직접 확인)

- [ ] 512×512 투명 배경
- [ ] "코피 펑" 만화 효과 — 빨간 분수 + 충격선 + 별 + 만화 글자
- [ ] 좌우 대칭 (얼굴 중앙 오버레이용)
- [ ] 외곽 검정 stroke 굵음 (캐릭터 위 겹쳐도 또렷)
- [ ] 글자가 얼굴 중앙 안 가림 (우상단 또는 좌상단 배치)
