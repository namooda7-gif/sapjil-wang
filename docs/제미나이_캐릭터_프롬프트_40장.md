# 삽질왕 캐릭터 생성 프롬프트 — char_002 ~ char_006 (총 40장)

> **사용법**: 각 프롬프트마다 📎 표시된 이미지를 Flow에 첨부하고, 📋 블록을 그대로 복붙. 한 캐릭터당 8장을 idle → dig → combo → surprise → clear → tired → panic → dig_hard 순으로 진행 (앞 포즈를 다음 포즈 레퍼런스로 사용).
>
> **공통 출력 규칙 (모든 프롬프트에 들어감)**:
> - PNG with alpha channel (RGBA 8-bit), 1536 × 2752 px (세로형 9:16)
> - 배경 완전 투명 (alpha = 0)
> - JPEG 금지, 정사각형 금지, 흰색·단색 배경 금지
> - 응답 마지막에 `format: PNG, alpha: yes, size: 1536x2752` 명시
>
> **공통 배치 규칙**:
> - 캐릭터를 이미지 가로 중앙
> - 발이 이미지 하단(y=2752)에 닿게 (발 아래 빈 투명 공간 X)
> - 캐릭터 크기 이미지 세로 90% 이상
